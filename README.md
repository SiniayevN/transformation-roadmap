# Sephora Digital Transformation: Roadmap, Governance & QBR Dashboard

## Overview
This repository contains the digital transformation planning artifacts for Sephora, structuring initiatives by capability dependency logic across **Crawl, Walk, and Run** maturity stages rather than historical release sequence[cite: 1, 2, 21].

## Artifacts & Structure
* `index.html` — Team landing page featuring team bios, target audience, strategic benefits, and the transformation novelty statement[cite: 14, 17].
* `dashboard.html` — Executive QBR Dashboard formatted as a single-page landscape review tool with 8 leading/lagging metrics, alert signals, and quarterly decisions[cite: 8, 20].
* `roadmap-raci.html` — Interactive view of the 7 sequenced initiatives and the 6-decision governance RACI matrix[cite: 7, 21, 22].
* `Sephora_Roadmap_RACI.pdf` — Static PDF deliverable containing the complete dependency logic and Accountable owner rationales[cite: 14, 21, 22].
